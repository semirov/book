# «Книга» — роман, который пишется публично

Живой роман: главы появляются прямо на одной странице, в открытую, и правки читателей
расходятся по тексту кругами, не ломая причинность. Сайт — **book.semirov.dev**.

Книга стоит пустой: 67 пронумерованных глав, четыре части без названий, две базисные фразы —
начало в главе 1 и конец в главе 67. Всё остальное пишется на глазах, в реальном времени.

## Канон

- `concept/CONCEPT.md` — идея (материя заметила себя; познание уходит с углерода на кремний;
  космос доходит до людей процедурой), тон и финал.
- `concept/CLIMAX.md` — единственная зафиксированная точка: углеродная форма не выживает.
- `style/VOICE.md` — голос: русская тоска, холод, киберпанк без неона; смесь манер, имён нет.
- `outline/PLAN.md` — план линий (не правило); `notes/canon-constraints.md` — что обязательно.
- `manuscript/` — единственный источник текста: `00-front.md` (название и аннотация), `chNN.md`.

## Сайт

```sh
cd site && npm install
npm run dev                  # API :8080 + Vite :5173
npm run build && npm start   # один процесс на :8080
npm run verify               # typecheck + arch + tests
npm run validate             # валидатор книги
```

Требования, решения, ADR, дизайн и прогоны — в Lific, проект BOOK.
